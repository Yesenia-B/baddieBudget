# baddieBudget
2026 SUNY Poly Computer Science Capstone Project
by Yesenia Burgos


              Baddie Budget | Full-Stack Budgeting Web Application
Technologies: HTML, CSS, JavaScript, Firebase Authentication, Firestore, Chart.js

• Designed and developed a full-stack budgeting application from requirements
gathering through implementation.
• Created relational data structures and CRUD functionality using Firestore.
• Designed user workflows and dashboards based on usability and business
requirements.
• Implemented secure authentication and role-based access using Firebase
Authentication.
• Integrated Chart.js dashboards to visualize financial trends and support data-
driven decision making.
• Used Git and GitHub to manage source control throughout development.
